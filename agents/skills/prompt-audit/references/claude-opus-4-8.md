Judge each prompt for how well it would elicit good work from Claude Opus:

- States the desired outcome and acceptance criteria up front, not after seeing
  output.
- Gives constraints (format, scope, length budget) before the agent acts, not as
  a later "instead of X, do Y" correction.
- Names concrete referents instead of "it"/"that"/"the thing".
- Does not assert unverified premises ("I thought X…") without flagging them as
  possibly wrong.
- Scopes the request explicitly rather than leaving the agent to guess breadth.
